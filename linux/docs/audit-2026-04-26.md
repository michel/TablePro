## 🟠 P1 — Flathub blockers (~2 days FT)

### Packaging

- [ ] **P1-1 AppStream metainfo file** · `flatpak/com.tablepro.Linux.metainfo.xml` (new) — id, summary, description, screenshots, ContentRating IASL-0, license declaration. Without this Flathub will refuse the submission.
- [ ] **P1-2 App icons** · `flatpak/icons/hicolor/{16,32,48,64,128,256,512}x.../apps/com.tablepro.Linux.png` + `scalable/apps/...svg`. Desktop file already references the missing icon name.
- [ ] **P1-3 Flatpak manifest installs metainfo + icons** · `flatpak/com.tablepro.Linux.json` build-commands.

### Keyboard & accessibility

- [ ] **P1-4 Keyboard shortcuts** — at minimum: `Ctrl+R` run query, `Ctrl+W` close dialog, `F5` refresh table, `Ctrl+E` SQL editor, `Ctrl+Q` quit, `Esc` already handled by `adw::Dialog`. Wire via `gio::ActionEntry` + `set_accels_for_action`.
- [ ] **P1-5 Keyboard shortcuts window** · `Ctrl+?` opens `gtk::ShortcutsWindow` listing them all.
- [ ] **P1-6 Accessible names on icon-only buttons** · `ui/app.rs` header (5 buttons + paginator prev/next) — `set_accessible_name(...)` in addition to tooltips.

### App identity

- [ ] **P1-7 About dialog** · `adw::AboutWindow` triggered from a hamburger menu in HeaderBar. Version, license, GitHub link.
- [ ] **P1-8 App menu (hamburger)** · gio::Menu with About, Help, (deferred: Preferences).

### Theme

- [ ] **P1-9 Dark mode follows system** · `ui/editor.rs:120` — replace hardcoded `Adwaita-dark` with `adw::StyleManager::default().is_dark() ? Adwaita-dark : Adwaita` and listen for `notify::is-dark`.

## 🟡 P2 — feature gaps (Sprint 2 candidates)

### Data grid ergonomics (every session)

- [ ] **P2-1 Column sort** · `ui/grid.rs:138` — `clickable(true)` + handler that re-fetches with `ORDER BY`. Track sort state, show indicator glyph.
- [ ] **P2-2 Find-in-results** · `Ctrl+F` over the loaded page; client-side filter for ≤10K rows, `WHERE col LIKE` for larger.
- [ ] **P2-3 Right-click cell context menu** — Copy value, Copy row as INSERT, Set NULL, Delete row.
- [ ] **P2-4 Multi-row select + bulk delete** — `gtk::MultiSelection`; show "Delete (N selected)" when >0.

- [ ] **P2-6 Row count in paginator** — `SELECT COUNT(*)` shown as "Rows 1–1000 of ~50K".
- [ ] **P2-7 Pagination size selector** — 100 / 1K / 10K. Currently hardcoded at `app.rs:20`.
- [ ] **P2-8 Column resize persistence** per (connection, table) via `gio::Settings`.
- [ ] **P2-9 Sticky column header** when scrolling horizontally — GTK 4.10's `freeze_columns()`.

### Workflow (power users)

- [ ] **P2-10 Query history with FTS** — `sqlx-sqlite` + FTS5 store, like macOS does.
- [ ] **P2-11 WHERE filter panel** — operators per column + saved presets.
- [ ] **P2-12 Export to CSV / JSON / SQL** — `gtk::FileDialog` save + small export crate.
- [ ] **P2-13 Test-connection button** in Connect dialog (separate from Save).
- [ ] **P2-14 Saved-connection rename / duplicate / folder organization**.
- [ ] **P2-15 Multiple SQL editor tabs** + tab persistence across restarts.

### Polish people will mention

## 🟢 P3 — polish

### UI consistency

- [ ] **P3-1 6/12/18/24 px margin grid** · `ui/app.rs:159–161` (table-search `8/4/8/8`).
- [ ] **P3-2 Reconnect attempt counter shows max** — "attempt 3" → "attempt 3/∞" or "will fail in 30s".
- [ ] **P3-3 SSH key path default** — pre-fill `~/.ssh/id_ed25519` then `~/.ssh/id_rsa` if it exists.
- [ ] **P3-4 Edit dialog PK affordance** — read-only field needs "(read-only)" subtitle.
- [ ] **P3-5 Window title shows active connection name** + table.
- [ ] **P3-6 Read-only badge on connection** — currently buttons hide; users don't know why.

### Accessibility

- [ ] **P3-7 Status messages announced by Orca** — `set_accessible_role(AccessibleRole::Alert)` on dim-label statuses.
- [ ] **P3-8 High-contrast theme test** — verify pills (success/warning) distinguishable without color.

### Code quality / observability

- [ ] **P3-9 `glib::timeout_add_seconds_local` SourceId leak** · `ui/app.rs:350` — store + cancel on shutdown.
- [ ] **P3-10 `connection_monitor` swap-and-set-health unit tests** — only `next_delay` math is covered today.

- [ ] **P3-13 Grid lazy binding for huge result sets** — currently O(n) eager allocation; fine at 10K cap, `gtk::ListView` is the long-term path.
